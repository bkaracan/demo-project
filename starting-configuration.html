4. Tek Tıkla Otomatik Zemin Hazırlama Betiği (PowerShell)

Aşağıdaki PowerShell script'ini doğrudan demo-project dizininde çalıştırarak tüm klasör hiyerarşisini, kural dosyalarını ve `AGENTS.md` anayasasını 3 saniye içinde oluşturabilirsiniz: 

# demo-project dizininde PowerShell ile çalıştırın:
$base = "C:\Users\burak\OneDrive\Masaüstü\demo-project"

# 1. Klasör Hiyerarşisini Oluştur
$folders = @(
  ".agents/rules", ".agents/subagents", "contracts", "db/migrations",
  "docs/planning", "docs/analysis", "docs/architecture/adr", "docs/reviews",
  "docs/qa", "docs/deploy", "docs/runbooks", "docs/postmortems", "docs/ops",
  "src/domain", "src/application", "src/infrastructure", "src/presentation", "src/config",
  "tests/unit", "tests/integration", "tests/load",
  "deploy/k8s", "deploy/prometheus", "deploy/grafana",
  ".github/workflows", ".husky"
)
foreach ($f in $folders) {
  $p = Join-Path $base $f
  if (-not (Test-Path $p)) { New-Item -ItemType Directory -Path $p -Force | Out-Null }
}

# 2. AGENTS.md Ana Anayasasını Oluştur
$agentsContent = @"
# DEMO PROJECT - AGENTIC SDLC MASTER CONSTITUTION
Bu repo Antigravity CLI ajanları tarafından uçtan uca yönetilen kurumsal bir projedir.

## TEMEL PRENSİPLER
1. Her faz (P1-P7) ve her adım (A1-A5) ilgili kural dosyasına (.agents/rules/) tam uymak zorundadır.
2. Kalite kapısı doğrulanmadan bir sonraki adıma ASLA geçilemez.
3. Test yazılmadan prodüksiyon kodu yazılamaz (TDD zorunluluğu).
4. Sır/API Key commit edilemez; GitLeaks kontrolleri atlanamaz.
5. Değişiklikler Conventional Commits formatında kaydedilir.
"@
Set-Content -Path (Join-Path $base "AGENTS.md") -Value $agentsContent -Encoding UTF8

# 3. Faz Kural Dosyalarını (.agents/rules/) Oluştur
$phases = @("00-general-sdlc", "01-planning", "02-requirements", "03-architecture", "04-development", "05-testing", "06-deployment", "07-maintenance")
foreach ($ph in $phases) {
  $ruleFile = Join-Path $base ".agents/rules/$ph.md"
  if (-not (Test-Path $ruleFile)) {
    Set-Content -Path $ruleFile -Value "# Rule: $ph`nBu fazda ilgili SDLC-PX-ICRA.html kılavuzundaki prompt ve kapılara sıkı bağlılık esastır." -Encoding UTF8
  }
}

Write-Host "TEBRİKLER: demo-project dizini ve Antigravity CLI zemin konfigürasyonu başarıyla hazırlandı!" -ForegroundColor Green
